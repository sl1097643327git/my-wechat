# 我的微信

“我的微信”是一款 Windows 桌面端微信伴随工具。它的目标很简单：让自己的聊天记录多一层本地安全保护。用户可以用自己设置的统一密钥，把准备发送的文字加密后再发送；收到可见的加密文本时，工具会在本机用透明浮层显示解密后的明文，方便自己阅读。

这个项目不修改微信、不注入微信、不 Hook 微信，也不读取微信内部数据。它只使用 Windows 正常提供的能力：UI Automation 识别当前可见窗口与消息区域、截图辅助判断消息方向、剪贴板/键盘输入发送文本，以及 PySide6 绘制本地浮层。

## 功能特点

- **本地加密发送**：输入明文后，工具使用统一密钥生成加密文本并发送到当前聊天。
- **本地解密浮层**：对当前可见的加密消息进行解密，并在微信聊天区域上方显示明文气泡。
- **自己管理密钥**：密钥保存在本机用户目录，聊天双方需要使用相同密钥才能正确解密。
- **不改动微信客户端**：不 Hook、不注入、不补丁、不逆向微信内部逻辑。
- **自动刷新**：可按设定间隔刷新当前可见消息的解密结果。
- **方向识别**：通过聊天区截图辅助判断消息来自左侧还是右侧，浮层气泡尽量贴近原消息方向显示。
- **复制明文**：解密气泡旁提供复制按钮，点击后写入系统剪贴板。
- **轻量面板**：提供加密输入、解密浮层、设置与退出按钮，默认展开，适合日常桌面使用。

## 适用场景

- 想给自己的日常聊天记录增加一层本地加密保护。
- 希望重要文字在聊天窗口中以密文形式保存，只在自己的电脑上临时显示明文。
- 想用一个不改动微信客户端的外部工具，辅助完成加密输入和本地解密阅读。

## 安装与运行

### 环境要求

- Windows
- Python 3.10+
- 桌面版微信 4.1.0~4.1.9（实测支持，其他版本请自行测试）

### 安装依赖

```powershell
python -m pip install -e .
```

如果需要运行测试：

```powershell
python -m pip install -e .[dev]
```

### 启动

```powershell
python -m wechat_overlay.app
```

启动后打开微信聊天窗口，设置统一密钥，即可使用加密输入、解密刷新和自动刷新功能。

## 使用说明

1. 打开桌面版微信并进入目标聊天。
2. 在“设置”面板输入统一密钥。
3. 在“加密输入”面板输入要发送的文字。
4. 按 `Enter` 发送；如需换行，使用 `Shift + Enter` 或 `Ctrl + Enter`。
5. 对方或自己发送的加密文本出现在当前可见聊天区域后，点击刷新或开启自动刷新。
6. 解密后的明文会以本地浮层气泡显示在聊天区域上方。
7. 点击气泡旁的复制按钮，可复制明文内容。

## 加密说明

- 当前加密文本前缀为 `密4:`。
- 使用 PBKDF2-HMAC-SHA256 从统一密钥派生加密密钥。
- 使用 AES-GCM 进行认证加密。
- 长文本在压缩收益足够时会自动压缩，减少最终密文长度。
- 解密失败时不会显示错误明文，只保留原始加密文本。

## 安全边界

“我的微信”提供的是本机使用层面的聊天文本加密辅助，不是完整的端点安全方案。请注意：

- 密钥由用户自己管理；密钥泄露后，对应密文可能被解密。
- 只处理当前窗口中可见的消息。
- 微信版本实测支持范围为 4.1.0~4.1.9，其他版本可能因 UI Automation 暴露信息差异而需要自行测试。
- 无法防护本机恶意软件、键盘记录、屏幕录制、截图或系统级监控。
- 不会改变微信自身的数据存储、同步、备份或账号安全机制。
- 建议只在自己信任的电脑上使用，并妥善保管统一密钥。

## 项目原则

- 只做外部伴随工具，不修改微信客户端。
- 明文只在本机浮层中展示，由用户自己决定何时复制和查看。
- 尽量保持轻量、透明、可测试，避免复杂依赖。
