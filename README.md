# 我的微信｜微信聊天加密小工具 🔐✨

想让微信里的重要文字多一层保护？这个小工具就是为这种场景准备的：

你输入明文 → 工具自动加密成密文发送；对方也下载这个工具，并设置**同一个密钥**，就可以在自己的电脑上看到解密后的内容啦。💬

> 简单理解：聊天窗口里保存的是密文，真正的明文只在本机浮层里显示。

## 它能做什么？🌟

- **加密发送**：输入想说的话，工具会用你设置的密钥加密后再发送。
- **同密钥阅读**：对方下载本项目后，设置和你一样的密钥，就能解密阅读。
- **浮层显示明文**：微信里看到的是密文，本机上方会显示透明解密气泡。
- **自动刷新**：打开自动刷新后，当前聊天里的可见密文会自动尝试解密。
- **一键复制**：解密气泡旁有复制按钮，想复制明文也很方便。
- **不改微信**：不 Hook、不注入、不补丁、不读取微信内部数据，更像一个桌面伴随工具。

## 适合谁用？🎯

- 想把重要聊天内容以密文形式留在聊天记录里的人。
- 想和朋友/同事共享一个密钥，互相发送加密文字的人。
- 想要一个轻量、不改动微信客户端的本地加密辅助工具的人。

## 双方怎么配合？👯

1. 你和对方都下载并运行这个项目。
2. 双方在“设置”里输入**完全相同的统一密钥**。
3. 你在“加密输入”里写文字并发送。
4. 对方在微信聊天窗口里看到 `密4:` 开头的密文后，点击刷新或开启自动刷新。
5. 如果密钥一致，对方电脑上就会显示解密后的明文气泡。✅

> 小提醒：密钥就像暗号，一定要私下安全告诉对方。密钥不一样，就读不出来；密钥泄露，别人也可能解密对应密文。

## 安装与运行 🧩

### 环境要求

- Windows
- Python 3.10+
- 桌面版微信 4.1.0~4.1.9（已实测；其他版本可以自行测试）

### 安装依赖

```powershell
python -m pip install -e .
```

如果你还想跑测试：

```powershell
python -m pip install -e .[dev]
```

### 启动工具

```powershell
python -m wechat_overlay.app
```

启动后，打开桌面版微信聊天窗口，设置统一密钥，就可以开始加密发送和解密阅读啦。🚀

## 日常使用流程 📌

1. 打开桌面版微信，进入目标聊天。
2. 在工具的“设置”面板里输入统一密钥。
3. 在“加密输入”面板输入要发送的文字。
4. 按 `Enter` 发送；如果要换行，用 `Shift + Enter` 或 `Ctrl + Enter`。
5. 当前聊天区域出现加密文本后，点击刷新或开启自动刷新。
6. 解密后的明文会以本地浮层气泡显示在聊天区域上方。
7. 需要复制时，点击气泡旁边的复制按钮即可。

## 加密方式说明 🛡️

- 当前加密文本前缀是 `密4:`。
- 使用 PBKDF2-HMAC-SHA256 从统一密钥派生加密密钥。
- 使用 AES-GCM 进行认证加密。
- 长文本在压缩收益足够时会自动压缩，减少密文长度。
- 解密失败时不会展示错误明文，只会保留原始加密文本。

## 安全边界要知道 ⚠️

这个工具提供的是“本机使用层面的聊天文本加密辅助”，不是完整的端到端安全方案。使用前建议了解这些边界：

- 密钥由你自己管理；密钥泄露后，对应密文可能被解密。
- 只处理当前微信窗口里可见的消息。
- 不会改变微信自身的数据存储、同步、备份或账号安全机制。
- 不能防护本机恶意软件、键盘记录、屏幕录制、截图或系统级监控。
- 微信版本差异可能影响识别效果，目前实测支持 4.1.0~4.1.9。
- 建议只在自己信任的电脑上使用，并妥善保管统一密钥。

## 项目原则 🌱

- 只做外部伴随工具，不修改微信客户端。
- 明文只在本机浮层中展示，由用户自己决定何时复制和查看。
- 尽量保持轻量、透明、可测试，避免复杂依赖。
